カード効果実装プレイブック

目的: 「カード効果を1つ追加する時に、どのファイルへ何を入れるか」を毎回同じ順序で進めるための手順書。

0. 方針（先に決める）

  • kind は処理内容だけを表す。
  • 任意効果は optional: true のように別プロパティで表す。
  • 即時解決できるなら instantHandlers.ts、ユーザー選択が必要なら pending で実装する。

1. 実装順序（毎回この順番）

  1. src/game/types.ts に EffectDef と PendingEffect を追加する。
  2. src/game/cardData.ts にカードの effects を追加する。
  3. src/game/effects/instantHandlers.ts にキーを追加する（pendingなら undefined）。
  4. src/game/effects/pending/* に init/resolve 実装を追加する。
  5. src/game/effects/pending/index.ts に registry 登録する。
  6. src/hooks/actions/resolveXxx.ts を追加し、useGame.ts に公開する。
  7. src/components/pending/XxxPanel.tsx を追加し、PendingEffectPanel.tsx に接続する。
  8. src/components/GameBoard.tsx から resolver を渡す。

2. 追加対象ファイルの一覧テンプレ

3. 最小テンプレコード

3-1. types.ts

type EffectDef =
  | { kind: "TopdeckFromDiscard"; max: number; optional?: boolean }
  | ...;

type PendingEffect =
  | { kind: "TopdeckFromDiscard"; max: number; optional: boolean }
  | ...;

3-2. pending 実装

export const topdeckFromDiscardPending = {
  init(state, effect) {
    if (effect.kind !== "TopdeckFromDiscard") return;
    state.pendingEffect = {
      kind: "TopdeckFromDiscard",
      max: effect.max,
      optional: effect.optional ?? false,
    };
  },
  resolve(state, payload) {
    if (!state.pendingEffect || state.pendingEffect.kind !== "TopdeckFromDiscard") return;
    // payload を検証して state を更新
    state.pendingEffect = null;
  },
};

4. 実装後チェック

  • npx tsc --noEmit が通る。
  • PendingEffect['kind'] に対して Record のキー欠けがない。
  • 新しい pending が UI から解決でき、解決後に pendingEffect = null へ戻る。
  • optional のときだけ「スキップ」導線を表示する。
