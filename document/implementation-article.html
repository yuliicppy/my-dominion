3. 状態管理とアクション

状態は useGame.ts が useState で保持し、 各操作は hooks/actions/* の関数に委譲している。 状態更新は cloneState を使ったイミュータブル更新。

useGame.ts（抜粋）

const [state, setState] = useState<GameState>(() => createInitialState());

function update(mutator: (next: GameState) => void) {
  setState(prev => {
    const next = cloneState(prev);
    mutator(next);
    return next;
  });
}

4. ゲームエンジンと効果解決

engine.ts で初期デッキ生成とドロー処理を管理。 効果は applyEffects が即時効果と保留効果を振り分ける。

applyEffects（抜粋）

export function applyEffects(state: GameState, effects: EffectDef[]): void {
  effects.forEach(effect => {
    const pending = pendingRegistry[effect.kind as keyof typeof pendingRegistry];
    if (pending) {
      pending.init(state, effect);
      return;
    }
    applyInstantEffect(state, effect);
  });
}

DiscardForDraw / TrashFromHand は UIパネルで選択し、resolve* で確定処理。

5. データ構造とカード定義

types.ts でカードと効果を型定義。 cardData.ts は基本セットのカードを並べ、 supply.ts が基本+王国の山札を作る。

EffectDef（抜粋）

export type EffectDef =
  | { kind: "DrawCards"; amount: number }
  | { kind: "AddActions"; amount: number }
  | { kind: "AddBuys"; amount: number }
  | { kind: "AddCoins"; amount: number }
  | { kind: "GainCard"; maxCost: number; destination: "discard" | "hand" }
  | { kind: "TrashCard"; amount: number; from: "hand" }
  | { kind: "DiscardForDraw"; min?: number; max?: number}
  | { kind: "TrashFromHand"; max: number;}
  | { kind: "If"; condition: Condition; then: EffectDef[]; else?: EffectDef[] }
  | { kind: "Repeat"; times?: number; until?: Condition; effect: EffectDef };
